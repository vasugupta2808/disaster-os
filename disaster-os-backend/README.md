# Disaster OS — Backend API

FastAPI backend for the Disaster OS AI Disaster Response Assistant.

## Setup

```bash
# Install uv if you don't have it: https://docs.astral.sh/uv/getting-started/installation/

# Install dependencies
uv sync

# Copy environment template and fill in real values
cp .env.example .env

# Download your Firebase service account JSON from:
# Firebase Console > Project Settings > Service Accounts > Generate New Private Key
# Save it as firebase-service-account.json in this directory (already gitignored)
```

## Run

```bash
uv run uvicorn app.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`. Interactive docs (Swagger UI)
are auto-generated by FastAPI at `http://localhost:8000/docs`.

Check the backend is alive:

```bash
curl http://localhost:8000/health
```

## Project structure

```
app/
  core/        # Config, exceptions, logging, Firebase init, auth dependency
  db/          # SQLAlchemy engine/session setup (relational data only)
  models/      # SQLAlchemy ORM models (added per-feature)
  schemas/     # Pydantic request/response schemas (added per-feature)
  routers/     # FastAPI route handlers (added per-feature)
  services/    # Business logic + external API integrations (added per-feature)
  main.py      # App factory - wires everything together
```
